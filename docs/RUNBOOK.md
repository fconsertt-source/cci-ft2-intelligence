# Runbook - دليل التشغيل والصيانة

## حالات الطوارئ

### عطل في قاعدة البيانات
```bash
# فحص الحالة
python scripts/health_check.py

# التراجع إذا لزم الأمر
python scripts/rollback.py

# إعادة تشغيل الخدمات
docker-compose restart cci-ft2-db
```

### مشاكل الأداء
```bash
# فحص السجلات
tail -f logs/audit.log

# تشغيل اختبار الحمل
python scripts/load_test.py

# إعادة تشغيل التطبيق
docker-compose restart cci-ft2-app
```

## الصيانة الدورية

### يومياً
- فحص السجلات للأخطاء
- التحقق من مساحة القرص
- فحص سلامة قاعدة البيانات

### أسبوعياً
- تشغيل النسخ الاحتياطي
- فحص الأداء
- تحديث التبعيات

### شهرياً
- مراجعة السجلات التاريخية
- فحص الأمان
- تحديث النظام

## مراقبة النظام

### مقاييس رئيسية
- استجابة API < 5 ثوانٍ
- معدل نجاح التقارير > 99%
- استخدام الذاكرة < 80%

### تنبيهات
- فشل في إنشاء التقرير
- تجاوز حد درجة الحرارة
- مشاكل في قاعدة البيانات
